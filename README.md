# Курсовая работа: Консольный аналитик операций OpenSky

Инструмент для парсинга, хранения и анализа данных о полетах воздушных судов на основе локального слепка данных OpenSky Network. Проект реализован на языке Python с применением объектно-ориентированного программирования (ООП) и модульного тестирования.

## 🛠️ Архитектура проекта

Проект разделен на логические слои (бизнес-логика, интерфейс, тесты, хранилище):
* `src/aeroplane.py` — модель данных самолета, инкапсуляция, валидация и правила сравнения.
* `src/connector.py` — абстрактный слой и логика взаимодействия с JSON базой данных.
* `src/console_ui.py` — интерактивный пользовательский интерфейс, логика отображения меню и таблиц.
* `src/main.py` — главная точка входа, связывающая парсинг исходного JSON-файла, сохранение в БД и запуск меню.
* `tests/test_app.py` — пакет автоматических юнит-тестов для проверки бизнес-логики и UI.

## 🚀 Инструкция по запуску

Запустить приложение можно двумя способами в зависимости от того, в какой директории открыт ваш терминал:

### Способ 1: Если терминал открыт в корне проекта (`Coursework_2`)
```bash
python src/main.py
```

### Способ 2: Если терминал открыт сразу в папке `src`
```bash
python main.py
```
```
